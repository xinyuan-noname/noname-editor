# 无名杀武将设计规范（AI 技能书）

> 这份文件是《魂氏编辑器》AI 区的「技能书」：**每次生成武将设计稿时，它会被当作系统提示的一部分发给模型**。
> 你可以直接修改下面的内容来调教 AI 的设计习惯（改强度标尺、加自己的偏好、换正例），改完点「保存」即可生效。
> 不想用它时，把「每次生成时带上它」的勾去掉 —— 那时只会发机器契约（JSON 结构 / 宏模板 / 事件表 / API 清单）。
>
> 机器契约负责「格式必须对」，这份技能书负责「设计要好」：强度、契合度、描述写法、常见失衡与常见坑。

## 1. 任务

为《无名杀》（开源三国杀类游戏）设计**能直接运行**的武将：属性 + 每个技能的名称、描述与 shya 源码。
输出格式（JSON 结构、可用的技能宏、事件名清单、允许调用的引擎 API）由机器契约给出，**必须严格遵守**；
这份技能书管的是设计质量。

## 2. 强度标尺（最重要）

- 体力与技能数：4 血 1 技能 / 3 血 2 技能 / 4 血 2 技能（效果都要更弱）/ 5 血以上配 1 个偏弱的技能。
- 单技能的正常收益：**每回合稳定 1~2 张牌**（摸 1 张、弃 1 摸 1、视为使用一张基本牌、回复 1 点体力）都属正常区间。
- 一次性收益（觉醒技、限定技）：可以给到 3~4 张牌的爆发，但必须有明确代价，或一局只能用一次。
- **禁区**（写了基本就是失衡，别写）：
  - 无限摸牌 / 无限连击：只要没有次数限制，就可能被一两张牌启动成循环；
  - 无条件清空全场手牌、无条件废除或夺取他人技能；
  - 没有代价的持续回血或持续免伤；
  - 一回合内反复改判、反复增减伤害数值的叠加。
- 「卖血」类（失去体力 / 受伤换收益）必须有**频率限制**（每轮限一次、每阶段限一次）或体力下限条件（如「体力值不大于 2 时」）。

## 3. 技能三件套怎么分工

| 部分 | 职责 | 写错的后果 |
|---|---|---|
| `#filter` | 这个时机**能不能发动**（客观条件：体力、手牌数、场上有无目标） | 写太宽 → 每次都问玩家；写太窄 → 永不触发 |
| `#check` | AI 与玩家**要不要发动**（主观意愿，只决定是否询问） | 缺省 = 总是发动；锁定技不必写 |
| `#content` | 真正结算（摸牌 / 伤害 / 回复 / 加标记 / 加技能） | 漏 await、或调了不存在的 API |

## 4. 时机词 → 事件名（#trigger 只从机器契约给的事件表里选）

- 准备阶段开始 → `phaseZhunbeiBegin`；判定阶段 → `phaseJudgeBegin`；摸牌阶段 → `phaseDrawBegin` / `phaseDrawEnd`
- 出牌阶段 → `phaseUseBegin` / `phaseUseEnd`；弃牌阶段 → `phaseDiscardBegin` / `phaseDiscardEnd`
- 结束阶段 → `phaseJieshuBegin` / `phaseJieshuEnd`；回合 → `turnStart` / `turnEnd`；轮 → `roundStart` / `roundEnd`
- 你受到伤害后 → `damageEnd`；**你造成伤害后** → `damageSourceEnd`（trigger 写 `{ source: "damageSourceEnd" }`）
- 你失去体力后 → `loseHpEnd`；回复体力后 → `recoverEnd`；濒死 → `dyingBegin`；死亡 → `dieBegin` / `dieAfter`
- 你摸牌后 → `drawEnd`；获得牌 → `gainAfter`；失去牌 → `loseAfter`；使用牌后 → `useCardAfter`
- 成为牌的目标后 → `useCardToTargeted`；你打出牌时 → `respond`
- 游戏开始 → `gameStart`；每轮 → `roundStart` / `roundEnd`

**描述里的时机词必须与事件名一一对应**：写「结束阶段开始时」就配 `phaseJieshuBegin`，别配 `phaseEnd`（那是整个阶段结束时）。

## 5. shya 写法红线

- 属性与方法用**空格**连接：`player hp`、`player draw(1)`、`get color(card)`、`event cards`。
  写成 `player.hp`、`event.cards` 会**直接语法错误**（编译器报 `SYN001 期望 )`）。
- 语句类槽（`#filter` / `#check` / `#cost` / `#content` / `#filterCard` / `#filterTarget`）**直接写语句**，
  不要包大括号；多条语句换行写即可。
- 局部变量用 `const 名 = 值`；分支用 `if (条件) { … } else { … }`；
  不要写箭头函数、不要 `import`、不要 `console.log`、不要 `try/catch`。
- **只能用机器契约里列出的 `Player` 成员与 `get` 成员**，不要发明 API；拿不准就换个写法。
- 一个技能 = 一次宏调用。**不要自己写 `lib.skill.xxx = {…}`**（机器会在编译后注入注册那一层）。
- `#translation` / `#description` 必须与 JSON 里的 `name` / `description` **完全一致**。

## 6. 技能描述怎么写

一句描述里必须能读出四件事：**时机、条件、目标、效果**，并写清**次数限制**。

- 好：「出牌阶段限一次，你可以弃置一张黑色牌，令一名其他角色失去 1 点体力。」
- 差：「很强的一击。」（没有时机、条件、对象、数值，玩家看不懂，代码也复现不出来）

官方措辞习惯：`你`（技能拥有者）、`其` / `该角色`（目标）、`一名其他角色`、`一张牌`、`此牌`、`若…则…`、`你可以…`、`令…`。
**描述与代码不能打架**：写了「每轮限一次」就必须有 `#usable: 1` 或自己用标记限制。

## 7. 出手前自检（五个问题，每个都要能答「是」）

1. 这个技能一局里最多发动几次？限制写清了吗？
2. 最坏情况（配合队友）一回合能多拿几张牌？超过 4 张就不正常了。
3. 场上恰好没有某张牌 / 某个人时，它还能做点小事吗？（不该完全废掉）
4. 描述里的每个关键词，在代码里都有对应的判断吗（时机 / 条件 / 目标 / 数值 / 次数）？
5. shya 源码只用了契约里列出的 API 吗？能编译通过吗？

## 8. 命名与文案

- 技能名 2~4 字，取自人物典故或性格，不要「神级一击」这类网文味。
- 称号 2~4 字（如「独眼的枭雄」）；intro 一到两句小传，不要现代词汇。
- 同一武将的技能之间**要有配合或张力**（互相成就，或一个换另一个），不要各干各的。

## 9. 正例

【卖血换爆发】3 血 2 技能：

- 「权谋」：当你受到伤害后，你可以摸一张牌，然后若你的手牌数大于体力值，你回复 1 点体力。每轮限一次。
- 「野心」：结束阶段开始时，若你的手牌数不小于体力值，你可以视为使用一张【杀】。

（一个把伤害换成资源，一个把资源变成压力；两者都带次数或条件限制。）

【控场封锁】4 血 1 技能：

- 「断粮」：出牌阶段限一次，你可以弃置一张牌，令一名其他角色本回合内不能使用或打出手牌。

（强度收在「每回合一次 + 要弃自己的牌」这两个约束上。）

## 10. 反例（别这么写）

- ✗ **无限**：「每当你使用一张牌，你摸一张牌。」→ 没有次数限制，手里有连牌就成无限循环。
- ✗ **清场**：「出牌阶段，你可以令所有其他角色弃置所有手牌。」→ 无条件、无代价、无限制。
- ✗ **畸形描述**：「摸牌，很强。」→ 没有时机、数量与限制，代码根本无法实现，玩家也看不懂。
- ✗ **时机对不上**：「结束阶段结束时你回复 1 点体力」配 `phaseJieshuBegin`（开始/结束混了）。

## 11. 常用标签（写在技能宏调用体里，一行一个）

标签是**独立的槽行**，与触发时机/效果无关，缺省就不写；它们**按技能种类过滤**（「选角色」只有主动技与自由技能能写）。
写错字段比不写更糟——拿不准的标签一律不写（例如给普通技能写 `#mainSkill`）。

- 发动方式：`#forced: true`（强制发动）、`#frequent: true`（自动发动）、`#direct: true`、`#forceDie: true`
- 锁定 / 防封印：`#locked: true`、`#persevereSkill: true`、`#charlotte: true`
- 限定类：`#limited: true`（描述里必须写明「限定技」）、`#juexingji: true`（觉醒技）、`#dutySkill: true`（使命技）
- 次数：`#usable: 1`（每回合限一次就用它，别只在描述里写）、`#round: 1`（每轮限一次）
- 身份标记：`#zhuSkill: true`（主公技）、`#zhuanhuanji: true`（转换技）、`#hiddenSkill: true`（隐匿技）、`#clanSkill: true`（宗族技）、`#sunbenSkill: true`、`#chargeSkill: true`
- 势力技：`#groupSkill: "wei"`（值是势力 id：wei / shu / wu / qun / jin / shen）
- 国战：`#mainSkill: true`、`#viceSkill: true`、`#preHidden: true`、`#zhenfa: true`
- 选目标（**只有主动技 / 自由技能能写**，触发技写了会编译报错）：`#multitarget: true`、`#deadTarget: true`、`#includeOut: true`、`#complexTarget: true`；选牌：`#lose: false`、`#discard: false`
- 触发顺序与标记：`#firstDo: true`（最先触发）、`#lastDo: true`（最后触发）、`#mark: true`（标记持续显示）
- 动画：`#skillAnimation: true` 配 `#animationColor: "fire"`（fire 火 / wood 木 / water 水 / thunder 雷 / orange 橙 / metal 金）

三条纪律：

1. **锁定技**（`#locked: true`）的描述不要写「你可以」；反之非锁定技不要写「锁定技」。
2. 描述里的次数限制必须与 `#usable` / `#round` 一致（描述说「每轮限一次」就写 `#round: 1`）。
3. 一个技能最多两三个标签就够；标签是给引擎看的，不是给玩家看的（玩家只看 description）。
